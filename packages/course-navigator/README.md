# Course Navigator

Course Navigator is a baseline agent that indexes local learning materials and answers questions with structured output.

## Features

- Structured output with `CourseAnswer` and `CourseReference`
- Dependency injection for personalization
- Static index of published learning materials
- Tooled access to lesson content with path validation

## Usage

Start the CLI (default):

```bash
just start course-navigator
```

Start the UI placeholder:

```bash
just start course-navigator ui
```
